The only mark the product has: a square speech bubble, bottom-leading corner notched, carrying the letter م.

```jsx
<BrandMark size={40} />
<BrandMark size={44} wordmark />
<BrandMark size={256} tone="rose" />
```

Rules: never outline it, never add a tail, never place it on a photo. The notch is always on the bottom-leading (right-to-left: bottom-left) corner. At icon sizes (256/512/1024) the mark fills the whole square — no padding ring.
